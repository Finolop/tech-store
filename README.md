Современный монорепозиторий интернет-магазина техники, потребительской электроники, геймерской периферии и софта. Проект включает в себя производительное клиентское приложение на **React 19 + TypeScript + Vite** и защищенный серверный **REST API на Express** с персистентным хранилищем данных, JWT-авторизацией и готовой бизнес-аналитикой.

---

## 🚀 Быстрый старт и пошаговая установка (Installation Guide)

### 1. Системные требования

- **Node.js:** версия `18.x`, `20.x` или `22.x` (LTS) — рекомендуется Node 20/22.
- **Пакетный менеджер:** `npm` (версия 9+), `pnpm` или `bun`.
- **Операционная система:** Windows 10/11, macOS или Linux.

---

### 2. Клонирование / распаковка и переход в каталог

```bash
cd tech-store
```

---

### 3. Настройка переменных окружения (`.env`)

Скопируйте файл конфигурации по умолчанию `.env.example` в `.env`:

**Windows (PowerShell):**

```powershell
Copy-Item .env.example .env
```

**Windows (CMD):**

```cmd
copy .env.example .env
```

**macOS / Linux:**

```bash
cp .env.example .env
```

Параметры файла `.env`:

- `PORT` — сетевой порт сервера (по умолчанию `3000`).
- `NODE_ENV` — режим (`development` или `production`).
- `JWT_ACCESS_SECRET` — секретный ключ подписи access-токенов.
- `JWT_REFRESH_SECRET` — секретный ключ подписи refresh-токенов.

---

### 4. Установка зависимостей

Выполните установку библиотек через `npm`:

```bash
npm install
```

_(Либо `bun install` при использовании среды Bun)._

---

### 5. Запуск в режиме разработки (Development)

Запустите единый сервер (Express API + Vite Dev Server с Hot Module Replacement):

```bash
npm run dev
```

После старта в консоли появится сообщение:

```text
[Server] Сервер ARCSHOP успешно запущен на http://localhost:3000
[Server] Режим работы: DEVELOPMENT
```

Откройте в браузере: **`http://localhost:3000`**

---

### 6. Сборка и запуск в Production режиме

Соберите оптимизированный бандл фронтенда и запустите сервер в боевом режиме:

```bash
# 1. Сборка клиентского SPA
npm run build

# 2. Запуск production сервера
npm start
```

Сервер автоматически подхватит статические файлы из каталога `dist/` и будет раздавать SPA вместе с защищенным API.

---

### 7. Доступные npm-скрипты

| Скрипт              | Описание команды                                                   |
| :------------------ | :----------------------------------------------------------------- |
| `npm run dev`       | Запуск сервера с встроенным Vite HMR для локальной разработки      |
| `npm run build`     | Оптимизированная сборка React-приложения в папку `dist`            |
| `npm start`         | Запуск сервера на порту 3000 в боевом режиме                       |
| `npm run preview`   | Локальный предпросмотр готовой сборки Vite                         |
| `npm run typecheck` | Строгая проверка типов TypeScript во всем проекте (`tsc --noEmit`) |
| `npm run lint`      | Алиас проверки типов                                               |
| `npm run clean`     | Кроссплатформенная очистка каталога сборки `dist`                  |

## Ключевые возможности платформы

### 1. Умное взвешенное сравнение (Smart Comparison)

- Матричное сравнение до 4 устройств одной категории (экраны, аккумуляторы, задержка отклика, вес, память, процессоры).
- Автоматическая нормализация параметров и расчет объективного итогового балла (0–100%).
- Определение категорий **«Лучший выбор»** и **«Максимум выгоды»** (Score / Price).

### 2. Система честных отзывов («Trust by Design»)

- Оставить отзыв на товар может **только реальный покупатель**, у которого в базе есть оплаченный заказ на этот артикул.
- Гости и пользователи без оплаченного заказа видят информационную плашку с условием допуска.
- Рейтинг 1–5 звезд с детализированной гистограммой распределения.

### 3. Вопросы и ответы (Q&A) с верификацией

- Вопросы к девайсам с древовидными ответами.
- Бейдж **«Купил этот товар»** для авторов с подтвержденными заказами.
- Официальные экспертные ответы магазина со статусом **«Магазин ARCSHOP»**.

### 4. Комплексный чекаут и допуслуги

- Выбор способа оплаты: Картой онлайн, СБП, Оплата частями (Сплит), Счет для юрлиц (B2B).
- Опция расширенной фирменной защиты **ArcCare+** (+8% к стоимости) с экспресс-заменой.
- Проверка и списание складских остатков в реальном времени.

### 5. Бизнес-модули

- **Калькулятор Trade-In:** экспресс-оценка старых гаджетов с выпуском промокода на скидку.
- **B2B-модуль:** автогенерация коммерческих предложений с выделением НДС 20% и скидкой 7% для юрлиц.
- **Чат-ассистент:** интеллектуальный онлайн-консультант по доставке, гарантии, рассрочке и софту.
- **Панель аналитики:** сводка выручки, среднего чека (AOV), маржи 22% и оповещения об остатках.

### 6. Дизайн и локализация

- 100% адаптивная верстка (мобильные телефоны, планшеты, десктоп).
- Полная мультиязычность интерфейса: переключение **RU / EN**.
- Поддержка цветовых тем: **Темная / Светлая / Системная**.

## Безопасность и надежность

- **Хеширование паролей:** bcrypt с солью (10 раундов).
- **Защита токенов:** сессионные токены хранятся в HttpOnly, SameSite cookies, предотвращая атаки XSS.
- **RBAC:** строгий контроль доступа к административным маршрутам на бэкенде.
- **Транзакционность склада:** остатки списываются атомарно при заказе и восстанавливаются при отмене.
- **Корректные 404:** API-запросы изолированы от SPA-маршрутов и возвращают валидный JSON 404 при неверном адресе.
